# clube — Backlog (2026-10-30, seventh)

Requests from 2026-10-30, kept as they were given (spelling tidied). They are organized in `Docs/clube-objectives.md`; the IDs below say where each went. Like the earlier backlogs, this file is a snapshot: change the objectives doc, not this.

---

- [ ] Bug: I was able to use a stump of a tree without removing any wood from above it. Also the press-E-to-open stump interaction range seemed to extend roughly 2x the player's height. Return this back to normal. → **GL240**
- [ ] Ensure that the shovel interacts very poorly with stone and ore materials (changing corner values by 0.1) while being very effective at soft materials (grass, dirt, clay). This tool should act essentially like the inverse of the pick. Right now it looks like it digs up stone and ore just as easily as dirt and grass, which is wrong. → **GL242**
- [ ] When you hover over a journal entry, don't highlight the text white, because then it looks like it's disappeared. → **GL243**
- [ ] When clicking on a bush to collect it, don't dig up the grass behind it. → **GL241**
- [ ] After sunset have the sun go down below the terrain and have a moon rise in a different part of the sky. Put in a real moon phase cycle so the moon has its own orbit and periodicity compared to the sun, modelled after the Earth, moon and sun relationship. Scale to 40 min for a 24 h cycle. → **GL248**
- [ ] Bug: when refining material on the stone boulder, there is overlapping white and yellow text near the cursor. → **GL244**
- [ ] C to slide while running doesn't work all the time; fix this. If you are running and press C, you should slide for as long as C is held, up to a certain slide distance. Don't allow sliding up hills, but flat and anything downhill should work. Slightly uphill is okay too. → **GL247**
- [ ] I dug up a bunch of clay, split the stack into a more manageable size, then very carefully refined that smaller stack to 100%. I went to the stump to craft a 100% quality clay furnace but it grabbed the lower % quality clay. I clicked on it to remove it from the input slot and it auto-stacked onto my pure 100% stack, mixing the pile again to ~55% quality. Don't allow auto-mixing like this with very different stack qualities, especially if a stack is at 100%. → **GL245**
- [ ] Silver/gold bun should be called button, not bun. → **GL244**
- [ ] Allow the merchant to buy decimal amounts, e.g. sell 46% 0.99 clay to the merchant. → **GL246**
- [ ] On the flat rock, Tin ingot should be top of the list. Copper should not come before it. → **GL244**
- [ ] Add a wooden chest to the game, costing 100 wood. It has the same number of slots as the player inventory at 100% quality wood, fewer as the quality of the wood used to craft it goes down, to a floor of 5 slots. Treat the chest as a buildable. Add it to the tool journal and to the crafting list at the stump. Allow selling it to the merchant. → **GL249**
- [ ] On the fauna side, have a crack at adding birds in the sky. Random groups of birds can be as small as 1 or as many as a flock. Have them swirl in varied bird patterns and fly away to disappear out of render distance. Make it look natural and not too busy in the sky, but gently add to the natural atmosphere of gameplay. → **GL250**
- [ ] Gold and chalcopyrite are hard to tell apart: add a bit more shine to the gold texture in the terrain and in the item slot picture. → **GL251**

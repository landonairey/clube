Dispatch prompt (short): "Read `Docs/batch-brief.md` (this week `Docs/handoff-20261125.md` replaces `Docs/handoff-20261116.md`). Batch <name>, GL <ids>, branch `<branch>` cut from `main`." plus the row's notes.
- Straight after each start, `get_session` and compare model AND effort with the row. `start_session` caps both at the driver's own, so raise them with `set_session_model` / `set_session_effort` before the batch's first turn does real work, and tell the user the confirmed model and effort in one line.

- FPS walk (`-walkbench`) skipped for every batch. The driver never implements; keep replies short.
